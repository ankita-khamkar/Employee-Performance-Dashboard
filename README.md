
# 📊 Employee Performance Dashboard

## 📌 Project Overview
This project analyzes employee performance data using Python to evaluate individual performance, compare departments, and identify top-performing employees.

The analysis transforms employee-level data into meaningful insights that support data-driven HR decisions.

## 🎯 Project Objectives
- Analyze employee performance across departments.
- Compare individual performance scores with department averages.
- Identify top-performing employees.
- Examine attendance, projects completed, and salary alongside performance.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
